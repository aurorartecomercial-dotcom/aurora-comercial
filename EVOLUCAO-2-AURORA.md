# Aurora Comercial — Evolução 2

Esta evolução foi feita sobre o projeto anterior, mantendo as cores e identidade visual.

## Principal melhoria: cadastro profissional de produtos
O painel administrativo agora permite cadastrar uma ficha de produto muito mais completa sem editar código:
- Marca
- SKU / código interno
- Destaques do produto (um por linha)
- Características técnicas (Nome: Valor)
- Selo de destaque
- Publicar/ocultar produto
- Data de atualização automática

## Loja
- Produtos marcados como inativos deixam de aparecer no catálogo público.
- A página do produto apresenta marca/SKU, selo, destaques e bloco de compra/entrega.
- Produtos relacionados respeitam o estado de publicação.
- Produtos vistos recentemente começam a ser registados localmente para futuras recomendações.
- Compatibilidade mobile preservada e reforçada.

## Compatibilidade
Os campos novos são opcionais. Produtos antigos continuam a funcionar sem precisar de edição imediata.
